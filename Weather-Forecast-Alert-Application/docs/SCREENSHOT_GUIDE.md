# Exactly which screenshots to take for your GitHub proof-of-work

**All included charts and reports are SIMULATED.** You should take your own screenshots after starting the project. Do not manufacture fake screenshots or claim simulated data is live.

1. `images/01-project-folder.png` — File Explorer showing `main.py`, `dashboard.py`, `src/`, `api/`, and `README.md`.
2. `images/02-terminal-simulation.png` — Double-click `RUN_DEMO_WINDOWS.bat`, capture the terminal with `SOURCE: SIMULATION (NOT REAL WEATHER)` visible.
3. `images/03-dashboard-current.png` — Double-click `RUN_APP_WINDOWS.bat`, capture the browser showing city, current values and source label.
4. `images/04-dashboard-alerts.png` — Scroll to the generated alert messages (keep SIMULATED label visible if using demo).
5. `images/05-dashboard-forecast.png` — Capture daily forecast table.
6. `images/06-dashboard-charts.png` — Capture 24-hour temperature and seven-day rain charts.
7. `images/07-report-and-csv.png` — Open `reports/` or `outputs/` and capture the generated report/CSV file.
8. `images/08-api-docs.png` — Start `RUN_API_WINDOWS.bat` and capture `http://127.0.0.1:8000/docs` in the browser.
9. `images/09-tests.png` — Capture terminal showing `python -m pytest -q` passing.
10. `images/10-github-repository.png` — Capture the public GitHub repository page after upload.

To take a screenshot on Windows: press **Win + Shift + S**, drag a rectangle over the desired screen area, then save the screenshot as PNG into `images/`.

Never show Telegram bot tokens, personal chat IDs, `.env`, passwords, or private personal locations. Use the included sample file `images/sample_simulated_Delhi_chart.png` as a reproducible chart proof even before you take screenshots.
